Questions

Is my data safe?

Yes. Everything stays on your local Wi-Fi, encrypted with TLS. Each phone is individually paired and authenticated — your Mac only obeys devices you approved. Camera and microphone are processed entirely on the iPhone and never transmitted. We collect nothing. See the privacy policy.

Why isn't Wield Host in the Mac App Store?

Apps that control the mouse and keyboard need the Accessibility permission, which Mac App Store rules don't allow. Wield Host is distributed the standard way for this category: downloaded directly, signed, and notarized through Apple's security check. Gatekeeper verifies it before it ever runs.

Is downloading from GitHub safe?

Yes — GitHub Releases is where a huge amount of trusted Mac software ships from (Rectangle, IINA, Stats, and many more). The download link on this page always points to the latest official release, and the app is notarized by Apple, so macOS independently verifies it hasn't been tampered with.

What does Wield Host need to work?

macOS 14 or later, and the Accessibility permission (System Settings → Privacy & Security → Accessibility) so it can move the cursor and type on your behalf. Live Screen additionally uses the Screen Recording permission — Wield Host's dashboard walks you through both.

Does it work over the internet?

By design, Wield works on your local network — a security feature: your Mac is never exposed to the internet. Pro users who want access from anywhere can pair Wield with a personal VPN like Tailscale (free for personal use): install it on both devices, then use "Connect by Address" in Wield. Same encryption, no accounts, no servers of ours in the middle.

Can it wake my Mac up?

Yes. Moving the trackpad wakes a dark display, and the Wake menu can wake a sleeping Mac over the network — just enable "Wake for network access" in System Settings → Battery → Options.

How do updates work?

Wield updates through the App Store like any iPhone app. Wield Host checks this site's releases once a day and shows a friendly banner when a new version is ready — nothing installs without you clicking it.

Is it laggy?

No. Wield speaks a tiny custom protocol over your local network — cursor moves arrive in a few milliseconds, which is why the trackpad feels like a real trackpad rather than a screen-share.

Support

Email owens.shunathon@gmail.com and you'll get a reply from a person. Most problems are one of these:

Wield can't find my Mac

Check three things: both devices on the same Wi-Fi, Wield Host running on the Mac, and Local Network permission allowed on the iPhone (Settings › Wield).

On hotel, café, campus, or airport Wi-Fi it will usually fail no matter what — those networks deliberately stop devices from seeing each other. Turn on Personal Hotspot on the iPhone and join the Mac to it; everything then works normally.

The cursor doesn't move

macOS needs to trust Wield Host: System Settings › Privacy & Security › Accessibility › enable Wield Host. Wield Host's own checklist links straight there.

Live Screen is blank

That's the Screen Recording permission: System Settings › Privacy & Security › Screen Recording › enable Wield Host, then relaunch Wield Host.

Some features are missing or greyed out

The Mac app is probably older than the iPhone app. In Wield Host's menu choose "Check for Updates…", or download the latest build above. Wield keeps working with an older Wield Host — it just can't do the newest things.

How do I remove it?

Drag Wield Host to the Trash. It installs nothing else, adds no login items you didn't enable, and leaves no background services behind.
